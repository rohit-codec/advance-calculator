# 🧮 Advanced Calculator

A modern, responsive and feature-rich scientific calculator built using
HTML, CSS and Vanilla JavaScript.

This project is designed as a frontend portfolio project and demonstrates
DOM manipulation, event handling, mathematical operations, LocalStorage,
keyboard events, responsive UI design and JavaScript logic.

## 📸 Features

### Basic Calculator

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal numbers
- Parentheses

### Scientific Calculator

- Square root
- Powers
- Square
- Factorial
- Sine
- Cosine
- Tangent
- Logarithm
- Natural logarithm
- Pi
- Euler's number

### Advanced Features

- DEG / RAD mode
- Calculation history
- LocalStorage
- Memory functions
- Dark mode
- Light mode
- Copy result
- Delete button
- Clear all
- Keyboard support
- Responsive design
- Error handling
